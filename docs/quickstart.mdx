# Quick Start Guide

Get NASA_ADC running on your local machine in under 5 minutes.

## Prerequisites




<CardGroup cols={2}>
  <Card title="Python" icon="python">
    Version 3.7 or higher
  </Card>
  <Card title="pip" icon="box">
    Package manager
  </Card>
</CardGroup>


## Installation

### 1. Clone Repository

```bash
git clone https://github.com/yogyam/NASA_ADC.git
cd NASA_ADC
```

### 2. Install Dependencies




```bash
# Create virtual environment (recommended)
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```


### 3. Environment Setup

```bash
# Copy environment template
cp .env.example .env

# Edit with your settings
nano .env
```

### 4. Start Application








```bash
python main.py
```


## Verify Installation


<Tip>
  Check the console output to verify the application started successfully.
