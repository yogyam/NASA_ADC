## Environment Variables

Create a production `.env` file:

```bash
# Application
NODE_ENV=production
PORT=3000

# Database
DATABASE_URL=your_database_url

# Authentication
JWT_SECRET=your_jwt_secret

# External Services
# Add your service configurations
```

## Deployment Methods

### Docker Deployment

```dockerfile
FROM python:3.9-slim

WORKDIR /app
COPY . .

RUN pip install -r requirements.txt
EXPOSE 8000
CMD ["python", "main.py"]
```

### Traditional Server

```bash
# Clone repository
git clone https://github.com/yogyam/NASA_ADC.git
cd NASA_ADC

# Install dependencies
pip install -r requirements.txt

# Start application
python main.py
```
