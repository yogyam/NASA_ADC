# Developer Guide

Complete technical guide for developers working on NASA_ADC.

## Development Environment

### Local Setup

1. **Clone Repository**
   ```bash
   git clone https://github.com/yogyam/NASA_ADC.git
   cd NASA_ADC
   ```

2. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Environment Configuration**
   ```bash
   cp .env.example .env
   # Configure your environment variables
   ```
